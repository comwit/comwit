## Existing admin screens

The default public entry is `/관리자`; `NEXT_PUBLIC_ADMIN_BASE_PATH` can change it. Internal `/admin` files remain stable and direct `/admin` requests return 404. Use `adminRoutes` for links and preserve server authorization. These are captures of the existing pages in Storybook with fixtures, not production records.

<ShopAdminScreens />

The existing stories live in `src/stories/admin/`, with API mocks in `src/stories/mocks/`. Keep those boundaries when changing the screens. Shared layer rules: [Project structure](/template/docs/structure).
