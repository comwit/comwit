# Getting started

Node.js 22.16 or later · pnpm 11.3.0

Download the [Shop Template source ZIP](https://github.com/comwit/template-shop/archive/refs/heads/main.zip) and extract it as `my-shop`. `npm create comwit@latest` is for the [base template](/template/docs/getting-started).

```bash
cd my-shop
pnpm install --frozen-lockfile
pnpm storybook
```

Preview pages with mock APIs in Storybook.

<a id="connect"></a>

## Connect your project

Prepare the environment with your Comwit project setup prompt, then request `shop-setup`. Follow the [resource connection guide](https://github.com/comwit/template-shop/blob/main/docs/shop-resources.md) for database and storage.

```bash
pnpm dev
```

For other services, see [integration settings](/template/docs/integrations).
