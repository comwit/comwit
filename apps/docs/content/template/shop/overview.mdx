# Shop Template

An editable Next.js shop with products, SKU inventory, cart, orders, payments and a separate admin service. The shared architecture and development rules come from [Base Template](/template/docs/structure).

[Shop Studio](https://comwit.io/shop-studio) presents 11 storefronts built with this shop backend. Browse their actual home and product-detail screens by brand type, then open an example to explore it.

## Already included

Customer pages cover browsing, cart, checkout and order history. Admin pages cover products, inventory, orders, payments, customers, notifications and connection settings. See the [actual page routes and admin screens](/template/docs/shop/pages).

Choose a direction with the [first-request skill](/template/docs/shop/skills), then adapt the existing pages. Reference screenshots are for visual guidance; use your own product images and brand assets in the new shop.
