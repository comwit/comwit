# Dedicated skills

`shop-setup` handles the first storefront request: choose a direction from the [real examples](/template/docs/shop/overview), adapt the existing pages and add Storybook states using mock APIs. Shared instructions remain in [Agent guides](/template/docs/agents).

<a id="resources"></a>

## Database and storage through MCP

Check existing bindings with `list_cloud_resources`; connect needed resources with `setup_database` / `setup_storage`. Apply local settings through the `nextSteps` returned by `get_local_env`. <ShopSourceLink path="docs/shop-resources.md">Connection guide</ShopSourceLink>

<a id="complete"></a>

## Finish once, keep developing

The one-time skill is removed after page/Storybook setup and validation succeed. Resume unfinished work from `.agents/state/shop-setup.json`.

Use `refactoring`, `seo-optimize` and `video-offload` for ongoing development.
