# Getting started

An **open-source Next.js project template** you can use and modify freely. Folder structure, agent guides, setup skills and validation rules are included.

```bash
git clone https://github.com/comwit/template.git my-app
cd my-app
pnpm install --frozen-lockfile
pnpm run dev
```

`npm create comwit@latest` still installs the existing npm release; this migration does not publish a new version.

<a id="included"></a>

## Included setup

Next.js App Router, `@comwit/state`, UI components installed as source, Oxlint rules and page-level Storybook are included. The base screens use mock data and can run and be edited without a Comwit account.

<a id="commands"></a>

## Main commands

| Command                   | Purpose                                             |
| ------------------------- | --------------------------------------------------- |
| `pnpm run dev`            | Development server                                  |
| `pnpm run validate`       | Type checking and lint                              |
| `pnpm run build`          | Production build; default output is `dist/brrrd`    |
| `pnpm storybook`          | Page previews with mocked APIs                      |
| `pnpm validate:storybook` | Storybook types, lint and API mock boundary checks  |
| `pnpm agents:test`        | Skill references and agent-related regression tests |

<a id="development"></a>

## Development flow

Read `AGENTS.md` and the guide for the layer you are editing. Update Storybook with screen changes and run `pnpm run validate`.

To use the included Comwit connections or adapt them to another environment, see [Default integrations](/template/docs/integrations).
