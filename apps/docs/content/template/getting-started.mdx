# Getting started

Node.js 22.16 or later · pnpm 11.3.0

```bash
npm create comwit@latest my-app -- --pm pnpm
cd my-app
pnpm run dev
```

Browse the base template on the [`main` branch](https://github.com/comwit/template/tree/main). Use its [README](https://github.com/comwit/template/blob/main/README.md) and [environment example](https://github.com/comwit/template/blob/main/.env.example) as setup references.

<a id="included"></a>

## Included setup

Next.js App Router, `@comwit/state`, UI components installed as source, Oxlint rules and page-level Storybook are included.

<a id="commands"></a>

## Main commands

| Command                   | Purpose                                             |
| ------------------------- | --------------------------------------------------- |
| `pnpm run dev`            | Development server                                  |
| `pnpm run validate`       | Type checking and lint                              |
| `pnpm run build`          | Production build; default output is `dist/brrrd`    |
| `pnpm storybook`          | Page previews with mocked APIs                      |
| `pnpm validate:storybook` | Storybook types, lint and API mock boundary checks  |
| `pnpm agents:test`        | Skill references and agent-related regression tests |

<a id="development"></a>

## Development flow

Read `AGENTS.md` and the guide for the layer you are editing. Update Storybook with screen changes and run `pnpm run validate`.

To use the included Comwit connections or adapt them to another environment, see [Default integrations](/template/docs/integrations).
