<a id="getting-started"></a>

# Getting started

```bash
npm create comwit@latest my-app
cd my-app
pnpm run dev
```

The CLI creates the project and installs dependencies. Ask your coding agent to read `AGENTS.md` before working in the generated project.

<a id="included"></a>

## Included setup

| Setup                      | Role                                               |
| -------------------------- | -------------------------------------------------- |
| Next.js App Router         | Routing and server execution                       |
| `@comwit/state`            | Domain models, queries and actions                 |
| `comwit-ui` + Tailwind CSS | UI components installed as source and style tokens |
| Oxlint + TypeScript        | Folder structure, import rules and type checks     |
| Storybook                  | Page previews with mocked APIs                     |

Data starts in an in-memory repository. A database connection and real authentication need separate setup; the `auth-setup` skill connects Better Auth and Drizzle.

<a id="commands"></a>

## Main commands

| Command                   | Role                                                           |
| ------------------------- | -------------------------------------------------------------- |
| `pnpm run dev`            | Development server                                             |
| `pnpm run validate`       | Type checking and lint                                         |
| `pnpm run build`          | Service worker and Next.js build                               |
| `pnpm storybook`          | Page previews                                                  |
| `pnpm validate:storybook` | Storybook types, lint and API mock boundary checks             |
| `pnpm agents:test`        | Skill reference consistency and agent-related regression tests |
| `pnpm ui add <name>`      | Add a UI component                                             |

<a id="deployment"></a>

## Deployment

The default is a standard Next.js project. For Cloudflare Workers, choose OpenNext when creating it.

```bash
npm create comwit@latest my-app -- --opennext
```

This adds OpenNext and Wrangler configuration, plus `preview` and `deploy` commands.
