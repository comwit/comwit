# Default integrations

Some settings are configured for Comwit by default. Use the integrations you need, or adapt the following parts to your preferred services and hosting environment.

| Default              | Purpose and edit points                                                                                                                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| brrrd adapter        | `adapterPath` in `next.config.ts` and `scripts/brrrd-adapter.mjs` produce `dist/brrrd` for Comwit deployment. For other hosting, adapt the adapter, related dependencies and deployment procedure.              |
| Comwit MCP           | `.mcp.json`, `.codex/config.toml` and `.agents/scripts/comwit-mcp.mjs` connect agents to Comwit tools. To use other tools, change these registrations and the integration instructions in `AGENTS.md` together. |
| Database and storage | `.env.example`, `src/server/config.ts` and `.agents/scaffolds/` define connection setup. For other services, adapt clients, environment variables, repository implementations and their guides.                 |

Base screens, Storybook, validation and builds work without an account. Project setup and login are needed only for actual Comwit tools, Cloud resources and deployment. Other hosting environments need the configuration changes above; they are not ready-to-deploy defaults.

[Comwit](https://comwit.io) is a service for building and deploying apps through conversation. To keep the default integrations, follow your project's setup prompt. The [source README](https://github.com/comwit/template/blob/main/README.md) describes the environment contract.
