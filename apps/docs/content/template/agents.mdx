# Rules and skills

Project instructions, setup skills and Oxlint checks.

<a id="guides"></a>

## Instruction files

| File                                                  | Role                                                                   |
| ----------------------------------------------------- | ---------------------------------------------------------------------- |
| `AGENTS.md`                                           | Project structure, stack, implementation order and validation commands |
| `CLAUDE.md`                                           | Claude Code entry point referencing `AGENTS.md`                        |
| `src/services/.ai.md`                                 | Service separation and import rules                                    |
| `src/services/api.ai.md`, `state.ai.md`, `page.ai.md` | File structure and implementation conventions for each layer           |
| `src/app/.ai.md`                                      | Routing and layout rules                                               |
| `src/server/repository/.ai.md`                        | Data models and read/write conventions                                 |
| `src/services/admin/.ai.md`                           | Admin routes and account rules                                         |
| `.storybook/stories/design-system/design.mdx`         | UI composition and style token guidance                                |
| `.storybook/stories/.ai.md`                           | Page story structure and API mocking rules                             |

Use the [base AGENTS.md](https://github.com/comwit/template/blob/main/AGENTS.md) and [Shop AGENTS.md](https://github.com/comwit/template/blob/shop/AGENTS.md) to find the source instructions and each layer’s `.ai.md`.

<a id="skills"></a>

## Setup skills

Base setup skills live in [main’s .agents/skills](https://github.com/comwit/template/tree/main/.agents/skills); `.claude/skills/` references the same source. For the storefront, use [shop-setup](/template/docs/shop/skills). Use them when the corresponding feature is needed.

| Skill          | Setup                                                                    |
| -------------- | ------------------------------------------------------------------------ |
| `app-setup`    | Bottom tabs, detail screens, page transitions and PWA install UI         |
| `auth-setup`   | Per-service Better Auth and Drizzle tables after a database is connected |
| `seo-optimize` | Metadata, JSON-LD, sitemap and robots                                    |

`refactoring` handles mock-to-database migration; `video-offload` moves site videos to external storage.

<a id="storybook"></a>

## Storybook

Base page states live in [.storybook/stories](https://github.com/comwit/template/tree/main/.storybook/stories); Shop stories live in [src/stories](https://github.com/comwit/template/tree/shop/src/stories). Stories use real pages, layouts and state, replacing only the API through [base mocks](https://github.com/comwit/template/tree/main/.storybook/mocks/api) or [Shop mocks](https://github.com/comwit/template/tree/shop/src/stories/mocks). Update stories alongside screen changes and run `pnpm validate:storybook` separately.
