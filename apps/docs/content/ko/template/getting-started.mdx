# 시작하기

자유롭게 가져다 쓰고 수정할 수 있는 **오픈소스 Next.js 프로젝트 템플릿**입니다. 폴더 구조, 에이전트 가이드, 스킬과 검사 규칙이 함께 준비되어 있습니다.

```bash
npm create comwit@latest my-app -- --pm pnpm
cd my-app
pnpm run dev
```

Node.js 22.16 이상과 pnpm 11.3.0을 준비하세요. 생성 명령이 의존성까지 설치합니다. 원본 저장소의 Git 이력은 가져오지 않으며, Git이 설치되어 있으면 새 프로젝트의 초기 커밋을 만듭니다.

<a id="included"></a>

## 포함된 구성

Next.js App Router, `@comwit/state`, 소스로 설치된 UI 컴포넌트, Oxlint 규칙, 페이지별 Storybook을 포함합니다. 기본 화면은 목 데이터로 시작하므로 Comwit 계정 없이 실행하고 수정할 수 있습니다.

<a id="commands"></a>

## 주요 명령어

| 명령어                    | 용도                                    |
| ------------------------- | --------------------------------------- |
| `pnpm run dev`            | 개발 서버                               |
| `pnpm run validate`       | 타입 검사와 린트                        |
| `pnpm run build`          | 프로덕션 빌드. 기본 출력은 `dist/brrrd` |
| `pnpm storybook`          | API를 모킹한 페이지 미리보기            |
| `pnpm validate:storybook` | Storybook 타입·린트·모킹 경계 검사      |
| `pnpm agents:test`        | 스킬 참조와 에이전트 관련 회귀 테스트   |

<a id="development"></a>

## 개발 흐름

`AGENTS.md`와 수정할 계층의 가이드를 읽고 작업합니다. 화면을 바꾸면 Storybook도 갱신하고, `pnpm run validate`로 확인합니다.

기본으로 포함된 Comwit 연동을 사용하거나 다른 환경으로 바꾸려면 [기본 연동 설정](/template/docs/integrations)을 참고하세요.
