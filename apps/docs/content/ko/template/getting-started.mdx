# 시작하기

```bash
npm create comwit@latest my-app
cd my-app
pnpm run dev
```

CLI가 프로젝트를 생성하고 의존성을 설치합니다. 생성된 프로젝트에서 코딩 에이전트에 `AGENTS.md`를 읽고 작업하도록 요청하세요.

<a id="included"></a>

## 기본 구성

| 구성                       | 역할                                    |
| -------------------------- | --------------------------------------- |
| Next.js App Router         | 라우팅과 서버 실행                      |
| `@comwit/state`            | 도메인별 상태·쿼리·액션                 |
| `comwit-ui` + Tailwind CSS | 소스로 설치된 UI 컴포넌트와 스타일 토큰 |
| Oxlint + TypeScript        | 폴더 구조, import 규칙, 타입 검사       |
| Storybook                  | API를 모킹한 페이지별 미리보기          |

데이터는 메모리 저장소로 시작합니다. 데이터베이스 연결과 실제 인증은 별도 설정이 필요하며, Better Auth와 Drizzle 연결은 `auth-setup` 스킬이 담당합니다.

<a id="commands"></a>

## 주요 명령어

| 명령어                    | 역할                                            |
| ------------------------- | ----------------------------------------------- |
| `pnpm run dev`            | 개발 서버                                       |
| `pnpm run validate`       | 타입 검사와 린트                                |
| `pnpm run build`          | 서비스 워커와 Next.js 빌드                      |
| `pnpm storybook`          | 페이지 미리보기                                 |
| `pnpm validate:storybook` | Storybook 타입·린트·API 모킹 경계 검사          |
| `pnpm agents:test`        | 스킬 참조 일치 여부와 에이전트 관련 회귀 테스트 |
| `pnpm ui add <name>`      | UI 컴포넌트 추가                                |

<a id="deployment"></a>

## 배포

기본은 표준 Next.js 프로젝트입니다. Cloudflare Workers에 배포하려면 생성 시 OpenNext 옵션을 사용합니다.

```bash
npm create comwit@latest my-app -- --opennext
```

이 옵션은 OpenNext·Wrangler 설정과 `preview`, `deploy` 명령어를 추가합니다.
