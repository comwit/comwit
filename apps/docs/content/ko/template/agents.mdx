# 규칙과 스킬

이 템플릿은 **규칙 파일, 설정 스킬, 린트 검증**을 함께 구성한 하네스 엔지니어링 예시입니다. 에이전트가 읽을 작업 기준을 저장소에 두고, 폴더 구조와 주요 의존성 규칙은 코드로 검사합니다.

<a id="guides"></a>

## 규칙 파일

| 파일                                                  | 역할                                              |
| ----------------------------------------------------- | ------------------------------------------------- |
| `AGENTS.md`                                           | 프로젝트 구조, 기술 스택, 작업 순서와 검증 명령어 |
| `CLAUDE.md`                                           | `AGENTS.md`를 참조하는 Claude Code 진입점         |
| `src/services/.ai.md`                                 | 서비스 분리와 import 규칙                         |
| `src/services/api.ai.md`, `state.ai.md`, `page.ai.md` | 계층별 파일 구성과 구현 방식                      |
| `src/app/.ai.md`                                      | 라우팅과 레이아웃 규칙                            |
| `src/server/repository/.ai.md`                        | 데이터 모델과 조회·저장 규칙                      |
| `src/services/admin/.ai.md`                           | 관리자 라우트와 계정 규칙                         |
| `src/services/design.md`                              | UI 구성과 스타일 토큰 사용 기준                   |
| `.storybook/stories/.ai.md`                           | 페이지 스토리 구성과 API 모킹 규칙                |

<a id="skills"></a>

## 설정 스킬

원본은 `.agents/skills/`에 있고, `.claude/skills/`는 같은 스킬을 참조합니다. 필요한 기능을 설정할 때 사용합니다.

| 스킬           | 설정 내용                                                       |
| -------------- | --------------------------------------------------------------- |
| `app-setup`    | 하단 탭, 상세 화면, 페이지 전환, PWA 설치 UI                    |
| `auth-setup`   | 데이터베이스 연결 후 서비스별 Better Auth 인증과 Drizzle 테이블 |
| `seo-optimize` | 메타데이터, JSON-LD, sitemap, robots                            |

<a id="storybook"></a>

## Storybook

`.storybook/stories/`에서 페이지별 상태를 확인합니다. 실제 페이지·레이아웃·상태 코드를 사용하고 `.storybook/mocks/api/`에서 API만 교체합니다. 화면 변경 시 스토리도 갱신하며, `pnpm validate:storybook`으로 별도 검증합니다.
