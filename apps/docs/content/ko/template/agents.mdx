# 규칙과 스킬

프로젝트 지침, 설정 스킬과 Oxlint 검사 규칙을 포함합니다.

<a id="guides"></a>

## 규칙 파일

| 파일                                                  | 역할                                              |
| ----------------------------------------------------- | ------------------------------------------------- |
| `AGENTS.md`                                           | 프로젝트 구조, 기술 스택, 작업 순서와 검증 명령어 |
| `CLAUDE.md`                                           | `AGENTS.md`를 참조하는 Claude Code 진입점         |
| `src/services/.ai.md`                                 | 서비스 분리와 import 규칙                         |
| `src/services/api.ai.md`, `state.ai.md`, `page.ai.md` | 계층별 파일 구성과 구현 방식                      |
| `src/app/.ai.md`                                      | 라우팅과 레이아웃 규칙                            |
| `src/server/repository/.ai.md`                        | 데이터 모델과 조회·저장 규칙                      |
| `src/services/admin/.ai.md`                           | 관리자 라우트와 계정 규칙                         |
| `.storybook/stories/design-system/design.mdx`         | UI 구성과 스타일 토큰 사용 기준                   |
| `.storybook/stories/.ai.md`                           | 페이지 스토리 구성과 API 모킹 규칙                |

원본 지침과 계층별 `.ai.md`는 [기본 템플릿 AGENTS.md](https://github.com/comwit/template/blob/main/AGENTS.md)와 [Shop AGENTS.md](https://github.com/comwit/template/blob/shop/AGENTS.md)에서 확인하세요.

<a id="skills"></a>

## 설정 스킬

기본 설정 스킬은 [main의 .agents/skills](https://github.com/comwit/template/tree/main/.agents/skills)에 있고, `.claude/skills/`는 같은 원본을 참조합니다. 쇼핑몰은 [shop-setup](/template/docs/shop/skills)을 사용하세요. 필요한 기능을 설정할 때 사용합니다.

| 스킬           | 설정 내용                                                       |
| -------------- | --------------------------------------------------------------- |
| `app-setup`    | 하단 탭, 상세 화면, 페이지 전환, PWA 설치 UI                    |
| `auth-setup`   | 데이터베이스 연결 후 서비스별 Better Auth 인증과 Drizzle 테이블 |
| `seo-optimize` | 메타데이터, JSON-LD, sitemap, robots                            |

`refactoring`은 목 데이터의 DB 전환을, `video-offload`는 영상의 외부 저장소 이전을 돕습니다.

<a id="storybook"></a>

## Storybook

기본 템플릿의 [페이지 스토리](https://github.com/comwit/template/tree/main/.storybook/stories)에서 상태를 확인합니다. Shop의 스토리는 [src/stories](https://github.com/comwit/template/tree/shop/src/stories)에 있습니다. 실제 페이지·레이아웃·상태 코드를 사용하고 [기본 템플릿 목](https://github.com/comwit/template/tree/main/.storybook/mocks/api) 또는 [Shop 목](https://github.com/comwit/template/tree/shop/src/stories/mocks)에서 API만 교체합니다. 화면 변경 시 스토리도 갱신하며, `pnpm validate:storybook`으로 별도 검증합니다.
