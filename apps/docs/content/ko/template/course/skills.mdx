# course-setup

예시 이미지에서 원하는 디자인을 고르면, `course-setup`이 그 방향을 바탕으로 내 브랜드와 강의에 맞는 수강생 화면을 개발합니다.

<a id="choose-a-design"></a>

## 이미지에서 디자인 고르기

[실제 예시 갤러리](/template/docs/course/overview)에서 PC·모바일 화면을 살펴보세요. 이미지를 누르면 홈, 강의 목록, 강의 상세 화면을 확인할 수 있습니다. 마음에 드는 화면이나 직접 준비한 참고 이미지를 프로젝트의 `references/` 폴더에 저장하고, 마음에 드는 배치, 여백, 글꼴, 색감 등을 에이전트에게 알려주세요.

> course-setup으로 시작해 줘. references/에 머니루틴 화면을 저장했어. 또렷한 강의 카드와 차분한 초록 색감이 좋아. 내 브랜드와 강의에 맞게 홈, 강의 목록, 강의 상세 페이지를 만들어 줘.

<a id="complete"></a>

## 선택한 디자인으로 개발하기

`course-setup`은 참고 이미지를 바탕으로 기존 수강생 화면인 홈·강의 목록·강의 상세·결제·강의실 플레이어·내 강의실을 디자인합니다. 브랜드에 맞춰 디자인을 적용하고, 기존 수강·결제·진도 기능을 이어서 사용합니다. 참고 이미지는 구성과 스타일의 방향으로만 쓰며 로고, 사진, 강의 내용은 복사하지 않습니다.

개발한 화면은 Storybook과 PC·모바일 프리뷰에서 확인하며 다듬습니다.
