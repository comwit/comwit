# 강의 템플릿

강의·수강·결제·관리자 화면이 준비된 강의 플랫폼. 이 템플릿으로 만든 실제 강의 사이트에서 원하는 분위기를 골라보세요.

소스는 [`comwit/template`의 `course` 브랜치](https://github.com/comwit/template/tree/course)에서 관리하며, `main` 브랜치가 공통 기반입니다.
