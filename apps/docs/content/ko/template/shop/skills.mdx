# shop-setup

`shop-setup`은 Shop Template의 첫 쇼핑몰 구성을 위한 전용 스킬입니다. [실제 예시](/template/docs/shop/overview)에서 방향을 정하고 기존 페이지를 수정하며, 목 API를 쓰는 Storybook 상태를 함께 구성합니다. <ShopSourceLink path=".agents/skills/shop-setup/SKILL.md">스킬 원문</ShopSourceLink>

<a id="resources"></a>

## MCP로 DB·스토리지 연결

`list_cloud_resources`로 기존 연결을 확인하고, 필요한 리소스는 `setup_database` / `setup_storage`로 연결합니다. 로컬 환경은 `get_local_env` 응답의 `nextSteps`로 설정합니다. <ShopSourceLink path="docs/shop-resources.md">연결 안내</ShopSourceLink>

<a id="complete"></a>

## 설정을 마치면

페이지·Storybook 구성과 검증이 끝나면 일회성 스킬이 제거됩니다. 미완료 작업은 `.agents/state/shop-setup.json`에서 이어갑니다.
