# shop-setup

예시 이미지에서 원하는 디자인을 고르면, `shop-setup`이 그 방향을 바탕으로 내 브랜드와 상품에 맞는 쇼핑몰을 개발합니다.

<a id="choose-a-design"></a>

## 이미지에서 디자인 고르기

[실제 예시 갤러리](/template/docs/shop/overview)에서 PC·모바일 화면을 살펴보세요. 이미지를 누르면 홈, 상품 목록, 상품 상세 화면을 확인할 수 있습니다. 원하는 예시를 고르고 마음에 드는 이미지 배치, 여백, 글꼴, 색감 등을 에이전트에게 알려주세요. 직접 준비한 참고 이미지로 시작해도 됩니다.

> shop-setup으로 시작해 줘. 윤슬 예시처럼 큰 이미지와 넓은 여백을 사용하고 싶어. 내 브랜드와 판매할 상품에 맞게 홈, 상품 목록, 상품 상세 페이지를 만들어 줘.

<a id="complete"></a>

## 선택한 디자인으로 개발하기

`shop-setup`은 선택한 이미지를 참고해 기존 쇼핑몰 템플릿의 홈·상품 목록·상품 상세 페이지를 수정합니다. 브랜드와 상품에 맞춰 디자인을 적용하고, 기존 장바구니·주문 등 쇼핑 기능을 이어서 사용합니다.

개발한 화면은 Storybook과 PC·모바일 프리뷰에서 확인하며 다듬습니다.
