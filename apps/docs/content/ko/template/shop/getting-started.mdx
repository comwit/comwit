# 시작하기

Node.js 22.16 이상과 pnpm 11.3.0을 준비하세요. [Shop Template 소스 ZIP](https://github.com/comwit/template-shop/archive/refs/heads/main.zip)을 내려받아 `my-shop` 폴더로 풉니다. 원본 Git 이력은 포함되지 않습니다. `npm create comwit@latest`는 현재 [기본 Template](/template/docs/getting-started)을 생성합니다.

```bash
cd my-shop
pnpm install --frozen-lockfile
pnpm storybook
```

Storybook은 실제 페이지에 목 API를 연결해 보여줍니다. DB·스토리지·결제 계정 없이 화면을 확인할 수 있습니다.

<a id="connect"></a>

## 프로젝트 연결

실제 상거래 앱은 Comwit 프로젝트의 설정 프롬프트와 포함된 MCP 브리지를 사용합니다. 에이전트에게 `shop-setup`을 요청하면 기존 연결을 확인하고, 승인된 범위에서 DB·스토리지 연결을 안내하며 상거래 스키마를 보존합니다. 자세한 순서는 [리소스 연결 안내](https://github.com/comwit/template-shop/blob/main/docs/shop-resources.md)에 있습니다.

필요한 프로젝트 환경을 준비한 뒤 앱을 실행합니다.

```bash
pnpm dev
```

DB 마이그레이션, 실제 결제와 배포는 별도 단계입니다. 실제 환경값은 Git에 넣지 않습니다. 공통 명령과 연동 교체 지점은 [기본 Template 연동 안내](/template/docs/integrations)를 참고하세요.
