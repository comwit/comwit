# Shop Template

상품, SKU 재고, 장바구니, 주문, 결제와 별도 관리자 화면이 준비된 수정 가능한 Next.js 쇼핑몰입니다. 공통 구조와 개발 규칙은 [기본 Template](/template/docs/structure)을 따릅니다.

[Shop Studio](https://comwit.io/shop-studio)는 이 쇼핑몰 백엔드를 활용한 11개 스토어 사례입니다. 브랜드 타입별 실제 홈·상품 상세 화면을 보고, 예시 사이트를 직접 열어볼 수 있습니다.

## 준비된 구성

구매자 화면에는 상품 탐색, 장바구니, 결제와 주문 내역이 있습니다. 관리자 화면에는 상품, 재고, 주문, 결제, 고객, 알림과 연결 설정이 준비되어 있습니다. [실제 페이지 경로와 관리자 화면](/template/docs/shop/pages)을 확인하세요.

[첫 요청 스킬](/template/docs/shop/skills)로 디자인 방향을 정한 뒤 기존 페이지를 수정합니다. 참고 화면은 디자인 가이드이며, 새 쇼핑몰에는 직접 사용할 수 있는 상품 이미지와 브랜드 에셋을 사용하세요.
