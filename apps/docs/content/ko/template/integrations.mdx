# 기본 연동 설정

템플릿의 일부 설정은 기본으로 Comwit에 맞춰져 있습니다. 필요한 연동만 사용하거나, 원하는 서비스·배포 환경에 맞게 아래 부분을 바꾸면 됩니다.

| 기본 설정        | 역할과 수정 지점                                                                                                                                                                  |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| brrrd 어댑터     | `next.config.ts`의 `adapterPath`와 `scripts/brrrd-adapter.mjs`가 Comwit 배포용 `dist/brrrd`를 만듭니다. 다른 호스팅을 쓰면 어댑터·관련 의존성과 배포 절차를 해당 환경에 맞춥니다. |
| Comwit MCP       | `.mcp.json`, `.codex/config.toml`, `.agents/scripts/comwit-mcp.mjs`가 에이전트를 Comwit 도구에 연결합니다. 다른 도구를 쓰면 이 등록과 `AGENTS.md`의 연동 지침을 함께 바꿉니다.    |
| DB·스토리지 연결 | `.env.example`, `src/server/config.ts`, `.agents/scaffolds/`가 연결 설정의 기준입니다. 다른 서비스를 쓰면 클라이언트·환경변수·리포지토리 구현과 관련 가이드를 맞춥니다.           |

기본 화면·Storybook·검증·빌드는 계정 없이 사용할 수 있습니다. 실제 Comwit 도구·Cloud 자원·배포를 사용하려는 경우에만 프로젝트 설정과 로그인이 필요합니다. 다른 호스팅에 그대로 배포되는 구성은 아니므로 위 설정을 먼저 조정하세요.

[컴윗](https://comwit.io)은 대화로 앱을 만들고 배포하는 서비스입니다. 기본 연동을 그대로 쓰려면 프로젝트의 설정 프롬프트를 따르세요. 세부 환경 계약은 [원본 README](https://github.com/comwit/template/blob/main/README.md)에 있습니다.
