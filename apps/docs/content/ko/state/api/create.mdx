# create()

모델과 액션 팩토리를 하나의 도메인 훅으로 결합합니다.

```ts
import { create } from '@comwit/state'
import { post } from './model'
import { crudActions } from './actions/crud'
import { loadActions } from './actions/load'
import type { PostState, PostActions } from './types'

export const usePost = create<PostState, PostActions>(post, {
  actions: [crudActions, loadActions],
})
```

읽기 전용 도메인에는 `{ actions: [] }`를 전달하세요.

<a id="select-the-state-you-render"></a>

## 렌더링할 상태 선택

```tsx
const { title, actions } = usePost((s) => ({
  title: s.detail.data?.title,
  actions: s.actions,
}))
```

선택자는 결과를 깊은 동등성으로 비교합니다. 이 예제는 제목이 바뀔 때 갱신됩니다. 대신 `s.detail`을 선택하면 쿼리 상태와 다른 데이터도 관찰합니다. 선택자 없이 `usePost()`를 호출하면 도메인 전체를 구독합니다.

<a id="server-data-with-suspend"></a>

## `.suspend()`로 서버 데이터 읽기

데이터를 렌더링하는 컴포넌트에서 `.suspend(arg)`를 선택하세요.

```tsx
'use client'

// Inside <Suspense>: the server render runs queryFn and streams the result
// when ComwitProvider has useServerInsertedHTML.
function PostDetail({ slug }: { slug: string }) {
  const post = usePost((s) => s.detail.suspend(slug))
  return post.data ? <article>{post.data.title}</article> : null
}
```

Server Component의 fetch나 어댑터가 필요 없습니다. `queryFn`은 서버와 브라우저 모두에서 실행됩니다.

대안: 서버 전용 코드가 필요한 읽기는 Server Component에서 기다린 뒤 훅의 `hydrate(entries)` 메서드로 항목을 초기화하세요.

```tsx
'use client'

// A Server Component awaited initialPost and passed it to this route adapter.
function PostRoute({ slug, initialPost }: Props) {
  usePost.hydrate({ detail: { arg: slug, data: initialPost } })
  return <PostView />
}
```

`hydrate(entries)`는 모델에서 쿼리 필드 이름, 인수, 데이터 타입을 추론합니다. 일반 도메인 읽기 전에 조건 없이 호출하세요. 반환값은 `void`이며 `null`이나 `undefined`를 받습니다. [Next.js 가이드](/state/docs/guide/nextjs)를 참고하세요.

<a id="load-a-query"></a>

## 쿼리 로드

타입이 `Query<Post[], { page: number }>`인 필드에서는 선택자에 인수를 전달하세요.

```tsx
const posts = usePost((s) => s.posts.load({ page }))

if (posts.isLoading) return <Skeleton />
if (posts.isError && !posts.isSuccess) return <p>{posts.error}</p>
return posts.data.map((post) => <Card key={post.id} post={post} />)
```

`.load(arg)`는 렌더링 중 로딩 상태를 표시하고 커밋 후 요청을 시작합니다. `.load(...)` 없이 `s.posts`를 선택하면 상태를 읽기만 합니다. 명령형 로딩과 여러 작업을 조율하는 흐름에는 액션을 사용하세요. 캐시 키, 최신성, `.suspend(arg)`는 [query()](/state/docs/api/query)를 참고하세요.

<a id="call-an-action"></a>

## 액션 호출

```tsx
const actions = usePost((s) => s.actions)

return <button onClick={() => actions.like(postId)}>Like</button>
```

액션은 현재 프로바이더에 바인딩됩니다. 상태 쓰기는 액션 안에 두고 이벤트나 명령형 작업 흐름에서 호출하세요. 렌더링 중 액션을 호출하여 스토어를 초기화하지 마세요.

<a id="lower-level-hooks"></a>

## 저수준 훅

`create()`는 아래 두 훅을 결합하고 타입이 지정된 하이드레이션 메서드를 추가합니다. 자체 통합을 구성할 때는 각각 사용할 수 있습니다.

```tsx
import { useModel, useAction } from '@comwit/state'

const title = useModel(post, (s) => s.detail.data?.title)
const actions = useAction<PostActions>([crudActions, loadActions])
```

둘 다 `ComwitProvider`가 필요합니다. `useModel()` 선택자도 같은 쿼리 `.load()` 인터페이스를 제공합니다.
